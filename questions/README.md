# Project Questions

This folder contains the questions used for the Myntra Fashion Clothing Data Analysis project.

## Question Categories

The project questions are divided into three sections:

### A. Data Cleaning and Preparation

This section covers:

- Duplicate value checking and removal
- Standardization of the `DiscountOffer` column
- Handling missing `DiscountPrice` and `DiscountOffer` values
- Handling missing `SizeOption` values

### B. Data Analysis

This section covers:

- Average original price for highly rated products
- Products with discounts greater than 50% OFF
- Products available in size M
- Classification of products into High Discount and Low Discount

### C. Data Retrieval and Lookup

This section covers:

- VLOOKUP/XLOOKUP
- INDEX and MATCH
- Nested XLOOKUP
- Product-level information retrieval using Product ID
