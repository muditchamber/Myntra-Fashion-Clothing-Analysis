# Analysis

This folder contains the analysis results of the Myntra Fashion Clothing dataset.

## Analysis Performed

The project includes:

- Average original price analysis
- Discount analysis
- Size availability analysis
- Discount classification
- Product-level lookup analysis

## Analysis Questions

The analysis covers questions related to:

1. Average original price for products with ratings greater than 4.
2. Number of products with discount greater than 50% OFF.
3. Number of products available in size M.
4. Classification of products into High Discount and Low Discount.
5. Product information retrieval using VLOOKUP/XLOOKUP.
6. Discount price retrieval using INDEX and MATCH.
7. Dynamic product information retrieval using nested XLOOKUP.
