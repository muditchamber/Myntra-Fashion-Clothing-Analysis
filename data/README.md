# Dataset

This folder contains the dataset used for the Myntra Fashion Clothing Data Analysis project.

## Files

### Myntra_Fashion_Clothing_Sample.xlsx

A sample version of the dataset is provided for GitHub preview and demonstration purposes.

The original dataset is larger than the standard GitHub browser upload limit, so the complete workbook is not stored directly in this repository.

## Dataset Fields

The dataset contains product-level information such as:

- Product ID
- Brand
- Category
- Individual Category
- Category by Gender
- Discount Price
- Original Price
- Size
- Ratings
- Reviews
- Discount Percentage

## Note

The sample dataset is included to demonstrate the structure and format of the original dataset. The complete dataset was used during the analysis workflow.
